# Île 8 — Citadelle du Crâne

## Direction officielle

L'île 8 utilise les trois références reçues le 26 juillet 2026 :

- forteresse construite dans un crâne rocheux monumental ;
- roster de sept personnages importants en 2.5D ;
- planche d'action pour les attaques, transformations et effets violets.

La zone est entourée d'une mer de magma et de roches volcaniques. L'accostage reste possible par un chenal praticable mais dangereux.

## Connexion au monde

- ordre : Île des Gâteaux → Citadelle du Crâne ;
- traversée réellement pilotable ;
- retour maritime possible vers l'île précédente ;
- roches de magma et dégâts de coque sur la dernière route ;
- position affichée sur la carte générale des huit îles ;
- aucun bouton de téléportation depuis la carte.

## Roster 2.5D

- Boss : Kaor, Seigneur du Crâne ;
- Commandants : Archonte de l'Aile Noire, Ravageur Cornu, Canon des Cendres ;
- Nakamas : Roi des Braises, Oracle Pourpre, Gardien Bestial.

Le cache reste limité aux sept personnages de l'île active. Les textures précédentes sont libérées au changement d'île.

## Environnement

- ciel sombre rouge et violet ;
- fumée épaisse et cendres animées ;
- forteresse-crâne avec yeux et gueule éclairés ;
- plateformes de basalte ;
- rivières de magma ;
- halo orange autour du littoral ;
- route maritime spéciale avec récifs volcaniques.

## État réel

Intégré :

- configuration commune de huit îles ;
- carte de l'archipel ;
- navigation avant et arrière ;
- route océanique vers l'île 8 ;
- mer de magma ;
- décor de la forteresse-crâne ;
- catalogue Java et tests des 56 ennemis importants ;
- métadonnées du roster ;
- fallback visible si l'atlas final est absent.

À terminer :

- bandes WEBP transparentes complètes dans les quatre directions ;
- animation image par image de chaque personnage ;
- modèles GLB des ennemis ordinaires et de la faune ;
- test visuel sur téléphone à partir de la prochaine APK compilée.
